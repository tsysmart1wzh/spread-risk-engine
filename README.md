# 日前价差风险评估与申报优化

版本：`v0.1.0`，当前源码基线，记录日期：2026-10-21。

本项目根据历史日前与实时价差生成目标日的24小时场景，以 Mean-CVaR 模型优化申报策略系数，进行滚动回测，并输出 Excel 报告。

本版本保存现有算法、默认参数和测试逻辑，供后续升级比较。人工策略目前作为对照基准，尚未成为优化的调整起点。收益采用单位申报基准下的价差收益。

## 当前流程

历史价格与人工策略 → 完整历史日场景抽样 → Mean-CVaR 优化 → 逐日真实价差回测 → Excel 输出。

| 模块 | 职责 |
| --- | --- |
| `工程化入口.py` | 命令行入口 |
| `spread_risk_engine/cli.py` | 命令行参数和结果摘要 |
| `spread_risk_engine/config.py` | 默认配置 |
| `spread_risk_engine/data.py` | 数据加载和策略校验 |
| `spread_risk_engine/scenarios.py` | 加权相似日 Bootstrap 与尾部历史日抽样 |
| `spread_risk_engine/optimization.py` | CVXPY 求解及 SciPy 备选求解 |
| `spread_risk_engine/metrics.py` | 收益、VaR/CVaR、场景覆盖率和质量标签 |
| `spread_risk_engine/backtest.py` | 滚动回测和基准比较 |
| `spread_risk_engine/reports.py` | Excel 报告生成 |
| `spread_risk_engine/types.py` | 场景和优化结果数据结构 |
| `run_engine_tests.py` | 现有数据、场景、优化和回测检查 |

## 默认参数

- 回测日期：2025-03-01 至 2025-03-31。
- 历史窗口：120天。
- 场景数量：5000；相似日占80%，尾部增强占20%。
- 风险厌恶系数：`beta=0.15`。
- CVaR 尾部概率：`0.05`，对应 CVaR95。
- 申报系数范围：`[0.8, 1.2]`。
- 价差：实时统一结算价减日前统一结算价。

## 环境与运行

项目元数据要求 Python 3.12 或更高版本。当前 `pyproject.toml` 的依赖列表为空，需单独安装源码使用的运行依赖：

```powershell
python -m venv .venv
.venv\Scripts\Activate.ps1
python -m pip install numpy pandas scipy cvxpy openpyxl
```

将本地输入文件放到项目目录，或通过命令行指定路径，再执行：

```powershell
python 工程化入口.py --start 2025-03-01 --end 2025-03-31
```

小范围运行并关闭报告写入：

```powershell
python 工程化入口.py --start 2025-03-01 --end 2025-03-03 --n-scenarios 300 --no-report
```

查看参数：

```powershell
python 工程化入口.py --help
```

## 本地数据要求

输入数据和已有报告不随本次源码基线上传，已由 `.gitignore` 排除。

1. 默认价差文件：`2025年1月到3月电价与价差数据.xlsx`。
   - 工作表：`电价合并结果`。
   - 必要字段：`日期_时刻`、`日前统一结算价`、`实时统一结算价`、`价差`。
   - 当前模型需要每天24个小时的数据。
2. 默认人工策略文件：`售电公司3月份交易数据.xlsx`。
   - 工作表：`策略表`。
   - 首列为行索引，例如 `1日`、`2日`。
   - 每行前24个数据列为小时策略系数。
   - 当前按日号查找，跨月份运行前需要升级日期标识。

也可通过 `--spread-file` 和 `--strategy-file` 传入其他输入路径。

## 输出

默认输出目录为 `工程化输出`。报告包含：`决策摘要`、`逐小时综合`、`场景质量`、`回测汇总`、`收益分布`。

当前报告文件名只包含风险水平和 beta；相同配置再次输出会覆盖同名报告。

## 已知局限

- 人工策略参与收益对比，没有进入优化目标或调整约束。
- 收益为单位基准价差收益，未接入主体实际电量、完整购售电结算、合约和零售风险传导。
- 报告的离散 VaR/CVaR 统计与优化模型的风险定义存在不一致，特别是分位点存在重复损失值时。
- 历史窗口回退按有记录的日期数判断，没有严格按完整日数量判断。
- 历史筛选使用目标日前日期，尚未按实际申报截止时点和数据发布时间控制信息可用性。
- 场景质量标签包含目标日真实价差，只能作为事后评价；低可信度建议尚未切换实际回测策略。
- 现有测试包含硬编码的 CVaR90 断言，与当前默认 CVaR95 不一致。
- 尚未纳入负荷、风电和光伏出力不确定性，也没有主体物理能力、正式市场规则或量价曲线接口。

这些问题保留在本版本中，作为后续修正和验证的比较基线。
